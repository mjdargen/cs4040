# Maps and tilesets — sources and credits

This directory contains maps and tilesets for [Tiled Map Editor](https://www.mapeditor.org/), used by the Pygame Zero Plus tilemap examples:

- `.tmx` — tilemaps and level layouts.
- `.tsx` — tileset definitions that refer to images.
- `.png` — tileset graphics.

Keep the `.tmx`, `.tsx`, and referenced `.png` files together so paths inside Tiled maps remain valid.

## Asset credits

- **[Kenney](https://kenney.nl/assets)** — the tileset names ending in `_kenney` identify Kenney-sourced art (including platformer and top-down tilesets). Kenney publishes these asset packs under **[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)**. Attribution is appreciated but not required.
- **[Tiled Map Editor](https://www.mapeditor.org/)** — the editor/file format used to build the `.tmx` and `.tsx` files; Tiled is a tool, not the art creator.
