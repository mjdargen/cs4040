Sounds

Sounds

Pygame Zero docs: Sounds

  • Used to play short sound effects, not music!
  • Store files in a folder called sounds (similar to images)
  • Filenames must be lowercase without spaces (.ogg or .wav)
  • Functions are called like so: sounds.<filename>.<function>()
sounds.thunder.play()  # plays the sound file called "thunder"
sounds.thunder.play(10)  # plays "thunder" 10 times
sounds.thunder.play(-1)  # plays "thunder" forever on a loop
sounds.thunder.stop()  # stops the "thunder" sound
sounds.thunder.get_length()  # gets the duration in seconds

Music

Music

Pygame Zero docs: Music

  • Used to play music and longer audio files.
  • Store files in a folder called music (similar to sounds)
  • Filenames must be lowercase without spaces (.ogg or .mp3)
music.play("interlude")  # plays file "interlude" on a loop
music.play_once("interlude")  # plays file "interlude" once
music.queue("jam")  # queues "jam" to play after the current track
music.is_playing()  # returns True if music is playing
music.stop()  # stops the music

Music Functions (cont’d)

Pygame Zero docs: Music

music.pause()  # pauses the current track
music.unpause()  # resumes the current track
music.fadeout(2.5)  # fades out the current track over 2.5 seconds
music.set_volume(0.5)  # sets volume to 0.5 (0 = silent, 1 = max)
music.get_volume()  # gets the current volume setting
