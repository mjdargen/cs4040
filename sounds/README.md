# Sound effects — sources and credits

This folder contains OGG sound effects, including interface sounds, movement, impacts, pickups, environmental sounds, and game events.

## Kenney audio

A large portion of the sound effects are credited to **[Kenney](https://kenney.nl/assets/category:Audio)**, whose game-audio packs are licensed under **[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)**. Attribution is appreciated but not required for confirmed CC0 files.
