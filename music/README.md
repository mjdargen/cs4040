# Music — sources and rights

This directory contains OGG background-music files used by the example games. **Not all files in this folder have the same reuse or redistribution rights.**

## Kenney music

Many tracks come from Kenney's [music-loop collections](https://kenney.nl/assets/category:Audio), distributed under **[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)**. Credit is appreciated, but not required for those confirmed tracks.

## Zelda: Ocarina of Time 8-bit arrangements

The files beginning with `zelda_oot_8bit_` are arrangements of music from **The Legend of Zelda: Ocarina of Time** from [here](https://www.youtube.com/watch?v=Lha7nX0RDck) as their source.
