# Images — sources and credits

This directory contains PNG assets used directly by example games, including character poses, animations, scenery, items, enemies, and UI elements.

## Known sources

- **[Kenney](https://kenney.nl/assets)** — many of the images match or are derived from Kenney game-asset collections, such as the platformer, character, and space-themed assets. Kenney's asset packs are generally published under **[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)**. Credit is appreciated, although CC0 does not require it.

Some images have been renamed, separated into individual frames, or repackaged for the course. **This ZIP does not contain a file-by-file source manifest**, so not every image can be definitively assigned to a particular Kenney pack. Avoid assuming every PNG in this directory is covered by Kenney's CC0 license until its origin is confirmed.
