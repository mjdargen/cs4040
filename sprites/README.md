# Sprite Documentation

This folder contains some example sprites that you can use for your projects. The `.png` files are the spritesheets you will use in your project. The `.md` files (also linked below) provide dimensions and information about each of the animations in the sprite. The `.aseprite` files are the source files used to create the sprites.

Read the `.md` files first by clicking the links for the sprite you want below. Each file provides metadata about the sprite, a breakdown of animations, and example usage code.

After adding or changing sprites, run `python utils/map_and_sprite_checker.py` from the repository folder to check that everything loads in Pygame Zero Plus.

## Asset credits

Sprites whose names end in an artist's name come from free asset packs. They may be shared and reused, including in commercial projects. Attribution isn't required, but please credit the artist, for example: *"Sprites: Ninja Adventure Asset Pack by Pixel-Boy and AAA (CC0)"*.

- **Pixel-Boy and AAA** — sprites ending in `_pixelboy`, from the [Ninja Adventure Asset Pack](https://pixel-boy.itch.io/ninja-adventure-asset-pack). Released under **[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)**. The pack has about 200 more characters, monsters, animals, and bosses, plus effects and items, if you want more.
- **analogStudios_** — sprites ending in `_analogstudios`: the knight is from [Camelot](https://analogstudios.itch.io/camelot) and the coin from [Four Seasons Platformer Sprites](https://analogstudios.itch.io/four-seasons-platformer-sprites). They come via the [Brackeys Platformer Bundle](https://brackeysgames.itch.io/brackeys-platformer-bundle), which Brackeys released under **[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)**.

The sheets were rearranged so that each animation is one row. Ninja Adventure characters and monsters have one row per direction, for example `walk_down`, `walk_up`, `walk_left`, `walk_right`.
