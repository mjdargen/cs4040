Event-Driven Programming

Per Wikipedia, “In computer programming, event-driven programming is a programming paradigm in which the flow of the program is determined by events such as user actions (mouse clicks, key presses), timers, sensor outputs, or messages from other programs or threads.”

Events include but are not limited to:

  • Key presses
  • Mouse clicks
  • Mouse movements
  • Timers

https://pgzero-plus.readthedocs.io/en/latest/hooks.html

Understanding Order

start()
while game_has_not_ended():
    process_input()
    update()
    draw()

Event Listener

An event listener is a bit of code that listens/waits for an event to occur (button press, mouse click, timer expiration) and executes a series of actions when the event occurs.

Event listeners allow the game/program to change during gameplay/execution.

Can be confusing at first. Event listeners seem asynchronous from draw()/update(), but we can think about it as interrupting that flow to tell us something has happened.

Mouse Events

def on_mouse_down(pos, button):
    print(f"Mouse button {button} clicked at {pos}.")

Note: There are also on_mouse_move & on_mouse_up listener functions. But not as commonly used.

pos is provided as a tuple, a list-like object that uses parentheses and cannot be changed.

pos = (x, y)
pos[0]  # x
pos[1]  # y

button = button that was clicked

Events vs. Polling

Event-based input Polling input
Idea something happens → you react you keep checking if something happened
Exp Text message notification. Interrupts. Notifications silenced. You have to check your phone.

Key Constants

Polling Inputs: Keyboard Polling in update()

# Moves Actor as long as key is pressed
def update():
    # checks if D key is pressed
    if keyboard.d:
        player.x += 1
    # checks if A key is pressed
    if keyboard.a:
        player.x -= 1

Note: Can’t use key in update(). That info is not passed to us like in keyboard event listeners. Must use keyboard.up, keyboard.a in update().

keyboard.<key> gives us a True/False value based on whether that key is pressed. Remains True if it is pressed.

Key Constants

Event-Based vs. Polling Inputs

Event-Based Inputs

Moves Actor up when key pressed. Happens once per press because on_key_down triggers once.

def on_key_down(key):
    if key == keys.UP:  # up key pressed
        player.y -= 10  # once per press

Good for single actions
Exp: jump, show other image

Polling Inputs

Moves Actor as long as key is pressed. Happens continuously because update() is called repeatedly.

def update():
    if keyboard.d:  # D key held down
        player.x += 1  # every frame

Good for continuous actions
Exp: movement, play animation

Clock Events

Callback Functions

Callback functions are functions you will define that will be called when a clock event occurs.

In this case move_character is the callback function:

# scheduled callback for moving character to random position
def move_character():
    robot.x = random.randint(50, WIDTH - 50)
    robot.y = random.randint(50, HEIGHT - 50)

Scheduled with the clock elsewhere in code:

clock.schedule_interval(move_character, 2.0)  # every 2 seconds

Make something happen later

Pygame Zero docs: Clock

We can create our time-based events using Clock methods!

  • clock.schedule_unique(callback, delay)
    • Waits for delay seconds, then calls the function callback. It cancels any previously scheduled calls to callback, so it only will execute once until it is scheduled again.
    • Exp: Game start delay, Game over delay before main menu.
  • clock.schedule(callback, delay)
    • Waits for delay seconds, then calls the function callback. This will add this callback to any other callback scheduled.
    • Exp: Spawning enemies, Triggering delayed sound.

Make something happen periodically

Pygame Zero docs: Clock

Instead of scheduling something to occur after a delay, we can schedule something to occur at an interval, every X seconds. We will use this the most!

  • clock.schedule_interval(callback, interval)
    • Schedules callback to execute every interval seconds.
    • Exp: Periodically spawn items, Auto move NPC

Be careful where you put schedule_interval()! Often put in start() or other places where we know it will only execute once. Otherwise a new interval is added every frame, and the calls pile up fast!

Make things stop happening!

Pygame Zero docs: Clock

We can cancel scheduled callbacks and scheduled intervals!

  • clock.unschedule(callback)
    • Cancels all previously scheduled callbacks for that function.
    • Exp: Cancel spawning and timer for game over screen.
  • clock.clear()
    • Cancels everything!
    • Exp: Stop spawning when moving to new level
